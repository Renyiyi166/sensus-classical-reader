# Sensus Classical Reader

Interactive MVP reader for Latin texts, published as a static GitHub Pages site.

Live domain target:

```text
https://koicosmos.com
```

Core files for the live site:

- `index.html` loads the reader.
- `preview.html` contains the static app shell and interaction script.
- `app/globals.css` contains the visual system.
- `data/passages.json` contains Caesar and Cicero sample annotations.
- `CNAME` binds the site to `koicosmos.com`.

The richer Next.js source can be restored locally from the Codex workspace when a package manager is available.
